# ideas/ — 想法深挖工作区

把脑子里的产品点子和抽象思考，沉淀成可发表文档的地方。

## 怎么用

1. **随手捕获**：有想法就在这建个文件（哪怕只写一句话），命名 `YYYY-MM-DD-标题.md`，从 `_template.md` 起步。捕获优先，先记下来不丢。
2. **深挖**：在 Claude Code 里运行
   ```
   /idea 你的想法
   ```
   它会带你走完：澄清 → 调研（带引用）→ 唱反调论证 → 成文。**阶段 2 和 4 需要你参与**，这两步才是真正帮你深度思考的地方。
3. **发表**：满意后把「可发表稿」并入站点周刊。

## 这套东西由什么组成

| 文件 | 作用 |
|------|------|
| `.claude/commands/idea.md` | `/idea` 流水线命令 |
| `.claude/agents/devils-advocate.md` | 专职唱反调的子 agent |
| `ideas/_template.md` | 文档模板 |
| `ideas/*.md` | 每个想法一个文件，既是工作区也是归档 |

底层调研能力复用了 Claude Code 自带的 `/deep-research`（多源搜索 + 对抗式校验 + 带引用报告）。

## 设计原则

- **半自动、人在环里**：最值钱的是"澄清"和"反方论证"，不全自动化，避免跳过思考。
- **事实与判断分开**：调研结论给来源，自己的观点显式标注。
- **先发散再唱反调**：默认对冲确认偏误，避免一路看多。
